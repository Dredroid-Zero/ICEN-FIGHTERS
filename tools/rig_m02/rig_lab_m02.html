Protótipo técnico · não é sprite jogável

1. Referência original aprovada

Arraste os pontos luminosos para marcar as articulações sobre a imagem. O desenho original não será alterado. A grade mostra apenas os pontos estimados do futuro rig.

2. Calibração da estrutura

Selecione e arraste um ponto.

Encaixes planejados

Cabeça / cabelo frente-trásTorso / camisetaPélvis / shortMãos / luvas / VFXPés / calçado

A hierarquia de ossos permanecerá padronizada para os seis corpos, mas as medidas e as peças de roupa serão ajustadas à silhueta de cada opção. Os golpes continuarão independentes das skins e dos efeitos.

3. Exportação de pontos

Exporte o JSON com as coordenadas revisadas para continuar o desenho das peças, primeiro da guarda, depois dos movimentos.

Atenção: estes pontos não criam automaticamente um boneco articulado. Antes de animar precisamos redesenhar corpo, camiseta e short em partes com transparência. Não usar a imagem com fundo como spritesheet.

Sem frameworks ou fontes externas. Funciona localmente e no GitHub Pages. O arquivo exportado fica apenas no seu dispositivo.
